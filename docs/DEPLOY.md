# Deploying for ₹0

The whole app is one Docker image: the Go binary serves the UI, API and WebSocket. Postgres runs on Neon.

## 1. Database (Neon)

1. Create a free project at neon.com, choosing the Singapore region if it is closest to your users.
2. Copy the **pooled** connection string (the host contains `-pooler`). It works because TradeCore avoids named prepared statements.
3. Migrations run automatically when the app starts.

The bots write constantly, which keeps Neon's compute awake. Check the current free compute allowance against your expected usage. If it is tight, slow the bots from the admin page or pause them when nobody is connected.

## 2. App (Render)

1. Push this repository to GitHub.
2. In Render choose **New → Blueprint** and select the repository. `render.yaml` creates one free Docker web service with a health check on `/api/v1/health`.
3. Set the secret environment variables:
   - `DATABASE_URL`: the Neon pooled string
   - `ADMIN_EMAILS`: your email, to get the admin page
   - `JWT_SECRET` is generated by the blueprint. Keep it, so sessions survive deploys.
4. Deploy, open the service URL, and sign up with your admin email.

Do not use Render's free Postgres; it expires after 30 days.

## 3. Keep it awake

Free Render services sleep after 15 idle minutes and take about a minute to wake. The UI shows a "waking up" screen meanwhile. To keep it awake for recruiters, create a free job at cron-job.org that requests `https://<your-service>.onrender.com/api/v1/health` every 10 minutes.

## Optional: Google sign-in

Create an OAuth client (type "Web application") in Google Cloud Console with the redirect URI `https://<your-service>.onrender.com/api/v1/auth/google/callback`, then set `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` and `PUBLIC_URL=https://<your-service>.onrender.com`.

## Optional: UI on Vercel

The single service is simpler. To host the UI separately anyway, build it with `VITE_API_URL=https://<api>/api/v1` and `VITE_WS_URL=wss://<api>/ws`, and set `FRONTEND_ORIGIN=https://<ui>` and `COOKIE_SAMESITE=none` on the API.
